# 小智本机网页

在自己的电脑上打开一个对话页，用来测试 [xiaozhi.me](https://xiaozhi.me/console/) 里的智能体。不需要把服务部署到服务器。浏览器只访问本机，对话仍走小智官方云。

每人用自己的小智账号。这个文件夹里没有现成的设备、密钥或知识库。下载后要自己添加智能体，并用验证码绑定。

## 准备

- Python 3.10 或更新版本
- 一个 xiaozhi.me 账号，以及要测试的智能体

安装 Opus：

- macOS：`brew install opus`
- Ubuntu / Debian：`sudo apt install libopus0 python3-venv`

## 启动

macOS / Linux：

```bash
chmod +x start.sh
./start.sh
```

Windows：双击 `start.bat`，或在该文件夹打开命令行后执行它。Windows 还需要系统能找到 `opus.dll`；找不到时，优先用 macOS 或 Linux。

第一次启动会建立 `.venv` 并安装依赖。看到类似下面这行后，用浏览器打开：

```text
网页对话页: http://127.0.0.1:8765/
```

端口被占用时可以换一个：

```bash
PORT=8766 ./start.sh
```

然后打开 `http://127.0.0.1:8766/`。

## 绑定智能体

1. 在网页点「添加」，填写一个本地名称，例如「会议向导」。这个名称只显示在本机列表里，方便切换。
2. 页面会出现 6 位验证码。打开 [xiaozhi.me 控制台](https://xiaozhi.me/console/)，进入要测试的智能体，点添加设备，填入这串验证码。
3. 回到网页，点「我已绑定，检查一下」，或等几秒。状态变成已接通后，可以打字或按住说话。
4. 要测另一个智能体，再点「添加」，用新验证码绑到另一个智能体。之后用下拉框切换。

官方云一台设备只能绑定一个智能体。这里每添加一次，就在本机生成一台虚拟设备，所以不用反复解绑。

验证码报「需要序列号」或提示无效时，点「验证码无效，重新取码」，只使用页面上最新的一串。绑定期间不要关掉这个网页。

## 不要上传的文件

首次运行后，本目录会出现这些文件，它们只属于这台电脑：

- `agents.json`：设备号和密钥
- `.venv/`
- `server.log`、`server.pid`

`.gitignore` 已经排除它们。推送到 GitHub 时不要强制加进去，也不要把 `agents.json` 发给别人。

## 测到的是什么

测到的是绑定账号里那个智能体的角色、知识库和工具。换一台电脑、换一个账号，就要重新绑定。关掉网页或停止脚本，只影响本机，不影响 xiaozhi.me 上的智能体配置。
