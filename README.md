# 熊城心本机测试页

在自己的电脑上打开一个网页，测试 [小智控制台](https://xiaozhi.me/console/) 里已经配好的智能体。不需要服务器，也不需要开发板。

网页只在你自己的电脑上打开。对话内容会送到小智官方云，使用你所绑定的那个智能体的角色、知识库和工具。

## 开始之前

请先确认这三件事：

1. 你能登录 https://xiaozhi.me ，并且看得到要测试的智能体。
2. 电脑已安装 Python 3.10 或更新版本。终端执行 `python3 --version` 可以检查。
3. 已安装 Opus 音频库。
   - Mac：打开终端，执行 `brew install opus`。如果提示没有 brew，先安装 [Homebrew](https://brew.sh/)。
   - Ubuntu / Debian：执行 `sudo apt install libopus0 python3-venv`。

仓库是私有的。如果克隆时提示没有权限，请让分享这个仓库的同事把你的 GitHub 账号加为协作者。

## 下载并打开

在终端执行：

```bash
git clone https://github.com/ftx66/xiaozhi-local-web.git
cd xiaozhi-local-web
chmod +x start.sh
./start.sh
```

第一次会自动安装依赖，需要等待一会儿。看到下面这行后，用浏览器打开 http://127.0.0.1:8765/ ：

```text
网页对话页: http://127.0.0.1:8765/
```

如果提示端口被占用，改用：

```bash
PORT=8766 ./start.sh
```

然后打开 http://127.0.0.1:8766/ 。

Windows 可双击 `start.bat`。若启动时报找不到 Opus，请改用 Mac 或 Linux。

要关掉测试页，回到运行脚本的终端，按 `Ctrl+C`。

## 绑定要测的智能体

每个智能体只需绑定一次。绑定期间不要关闭测试页，也不要停止脚本。

1. 在测试页点击「添加」，填一个便于识别的名称，例如「会议向导」或「校园支持」。这个名称只显示在你的电脑上。
2. 页面会给出一串 6 位验证码。
3. 打开 https://xiaozhi.me/console/ ，进入要测试的那个智能体，点击添加设备，填入这串验证码。
4. 回到测试页，点击「我已绑定，检查一下」。也可以等几秒，页面会自动检查。
5. 状态变为已接通后，可以在右侧打字，或按住左侧按钮说话。浏览器询问麦克风权限时，选择允许。

要测试另一个智能体时，再点一次「添加」，用新的验证码绑定。绑定过的智能体可以在页面上方的下拉里随时切换，不必到控制台解绑。

控制台如果提示「需要序列号，请检查设备是否已烧录」，或提示验证码无效，不要重复提交旧验证码。回到测试页，点击「验证码无效，重新取码」，只使用页面上最新的一串。

## 测试时请注意

- 你测到的是控制台里该智能体当前的配置。角色介绍、知识库改过并保存后，重新开一轮对话即可。
- 关闭网页或停止脚本，只停止你这台电脑上的测试，不会改动控制台上的智能体。
- 换一台电脑时，需要重新下载并重新绑定。
- 运行后，文件夹里会出现 `agents.json`。它包含这台电脑的设备密钥，请不要发给别人，也不要提交回这个仓库。
